Application startup flow

LockGate uses the same flow in local development, Docker, CI, and production.

Use it from any programming language.

Applications communicate with LockGate over JSON and HTTP. No LockGate SDK or Go package is required. The server itself is written in Go, but your application can use JavaScript, Python, PHP, Java, Rust, or any HTTP client.

  1. 1
    Create a secret

    Open Secrets and add a path such as projects/crypto/prod/database.

  2. 2
    Create an application

    Open Applications, set its environment and allowed paths, then save the token shown once.

  3. 3
    Request secrets at startup

    The application sends only its token. LockGate resolves its application, environment, and assigned secrets on the server.

  4. 4
    Approve access

    The request appears under Approvals. Once approved, restarts keep working until the grant is revoked.

Application configuration

Pass the URL and one-time application token through the runtime environment.

Environment variables
LOCKGATE_URL={{.PublicURL}}
LOCKGATE_TOKEN=lg_app_your_token_here
Keep the token private. Do not commit it to Git, bake it into a Docker image, or print it in application logs.

Docker Compose example

compose.yaml
services:
  backend:
    image: your-backend:latest
    environment:
      LOCKGATE_URL: {{.PublicURL}}
      LOCKGATE_TOKEN: ${LOCKGATE_TOKEN}

Raw HTTP API with curl

Start an access request with an application token. The idempotency key identifies one running instance; use a different value for every replica.

Request access
curl --request POST '{{.PublicURL}}/api/v1/access' \
  --header "Authorization: Bearer $LOCKGATE_TOKEN" \
  --header 'Content-Type: application/json' \
  --header "Idempotency-Key: $(cat /proc/sys/kernel/random/uuid)" \
  --data '{}'

Without an active grant, LockGate returns HTTP 202:

{"status":"waiting_approval","request_id":"...","retry_after":3}

Poll the returned request ID at the advised interval:

Poll request
curl '{{.PublicURL}}/api/v1/access/REQUEST_ID' \
  --header "Authorization: Bearer $LOCKGATE_TOKEN"

Language examples

Each example uses the same token-only HTTP flow. Choose your language.

startup.mjs · Node.js 18+
const url = process.env.LOCKGATE_URL;
const token = process.env.LOCKGATE_TOKEN;
const headers = {
  Authorization: `Bearer ${token}`,
  "Content-Type": "application/json",
  "Idempotency-Key": crypto.randomUUID(),
};

let response = await fetch(`${url}/api/v1/access`, {
  method: "POST",
  headers,
  body: JSON.stringify({}),
});
let access = await response.json();

while (access.status === "waiting_approval") {
  await new Promise(resolve => setTimeout(resolve, access.retry_after * 1000));
  response = await fetch(`${url}/api/v1/access/${access.request_id}`, {
    headers: { Authorization: `Bearer ${token}` },
  });
  access = await response.json();
}

if (access.status !== "approved") throw new Error(`Access ${access.status}`);
const bundles = Object.values(access.secrets);
if (bundles.length !== 1) throw new Error("Expected one configured bundle");
const values = bundles[0];
startup.py · Python 3
import json
import os
import time
import urllib.request
import uuid

url = os.environ["LOCKGATE_URL"]
token = os.environ["LOCKGATE_TOKEN"]
headers = {
    "Authorization": f"Bearer {token}",
    "Content-Type": "application/json",
    "Idempotency-Key": str(uuid.uuid4()),
}
request = urllib.request.Request(
    f"{url}/api/v1/access", json.dumps({}).encode(), headers
)
with urllib.request.urlopen(request, timeout=15) as response:
    access = json.load(response)

while access["status"] == "waiting_approval":
    time.sleep(max(access.get("retry_after", 3), 3))
    request = urllib.request.Request(
        f"{url}/api/v1/access/{access['request_id']}",
        headers={"Authorization": f"Bearer {token}"},
    )
    with urllib.request.urlopen(request, timeout=15) as response:
        access = json.load(response)

if access["status"] != "approved":
    raise RuntimeError(f"LockGate access {access['status']}")
bundles = list(access["secrets"].values())
if len(bundles) != 1:
    raise RuntimeError("Expected one configured bundle")
values = bundles[0]
There is no published LockGate Go package. No external SDK is required: copy the small client below into your project, or import pkg/client when working inside this source module.
main.go · application usage
package main

import (
    "context"
    "log"
    "os"
    "time"

    lockgate "your-project/internal/lockgateclient"
)

func main() {
    client := lockgate.New(os.Getenv("LOCKGATE_URL"), os.Getenv("LOCKGATE_TOKEN"))
    ctx, cancel := context.WithTimeout(context.Background(), 10*time.Minute)
    defer cancel()

    values, err := client.GetConfig(ctx)
    if err != nil {
        log.Fatal(err)
    }
    dbPassword := values["DB_PASSWORD"]
    _ = dbPassword // Pass it to your database config; never log it.
}

Go client implementation

This is the complete client used by the example. It sends only the token, waits at the server-advised interval, and fails closed on denial or malformed responses.

internal/lockgateclient/client.go
package lockgateclient

import (
    "bytes"
    "context"
    "crypto/rand"
    "encoding/hex"
    "encoding/json"
    "errors"
    "fmt"
    "io"
    "net/http"
    "net/url"
    "strings"
    "time"
)

type Client struct {
    url, token string
    http       *http.Client
}

type accessResponse struct {
    Status     string                       `json:"status"`
    RequestID  string                       `json:"request_id"`
    RetryAfter int                          `json:"retry_after"`
    Secrets    map[string]map[string]string `json:"secrets"`
}

func New(url, token string) *Client {
    return &Client{
        url:   strings.TrimRight(url, "/"),
        token: token,
        http: &http.Client{
            Timeout: 15 * time.Second,
            CheckRedirect: func(*http.Request, []*http.Request) error {
                return http.ErrUseLastResponse // Never forward a token to another origin.
            },
        },
    }
}

func (c *Client) GetConfig(ctx context.Context) (map[string]string, error) {
    instance := make([]byte, 24)
    if _, err := rand.Read(instance); err != nil {
        return nil, errors.New("lockgate: cannot create request identity")
    }

    result, err := c.call(ctx, http.MethodPost, "/api/v1/access", []byte(`{}`), hex.EncodeToString(instance))
    for err == nil {
        switch result.Status {
        case "approved":
            if len(result.Secrets) != 1 {
                return nil, errors.New("lockgate: expected one configured bundle")
            }
            for _, values := range result.Secrets {
                return values, nil
            }
        case "denied":
            return nil, errors.New("lockgate: access denied by administrator")
        case "waiting_approval":
            if result.RequestID == "" || strings.ContainsAny(result.RequestID, "/?#") {
                return nil, errors.New("lockgate: response has an invalid request ID")
            }
            delay := max(result.RetryAfter, 3)
            select {
            case <-ctx.Done():
                return nil, ctx.Err()
            case <-time.After(time.Duration(delay) * time.Second):
            }
            result, err = c.call(ctx, http.MethodGet, "/api/v1/access/"+url.PathEscape(result.RequestID), nil, "")
        default:
            return nil, fmt.Errorf("lockgate: unexpected status %q", result.Status)
        }
    }
    return nil, err
}

func (c *Client) call(ctx context.Context, method, path string, body []byte, idempotencyKey string) (accessResponse, error) {
    var result accessResponse
    base, err := url.Parse(c.url)
    if err != nil || base.Host == "" || (base.Scheme != "https" && base.Scheme != "http") || base.User != nil || base.Path != "" {
        return result, errors.New("lockgate: URL must be an HTTP(S) origin")
    }
    request, err := http.NewRequestWithContext(ctx, method, c.url+path, bytes.NewReader(body))
    if err != nil {
        return result, err
    }
    request.Header.Set("Authorization", "Bearer "+c.token)
    if body != nil {
        request.Header.Set("Content-Type", "application/json")
    }
    if idempotencyKey != "" {
        request.Header.Set("Idempotency-Key", idempotencyKey)
    }

    response, err := c.http.Do(request)
    if err != nil {
        return result, errors.New("lockgate: server unreachable or request timed out")
    }
    defer response.Body.Close()
    if response.StatusCode != http.StatusOK && response.StatusCode != http.StatusAccepted {
        return result, fmt.Errorf("lockgate: request rejected (HTTP %d)", response.StatusCode)
    }
    if err := json.NewDecoder(io.LimitReader(response.Body, 16<<20)).Decode(&result); err != nil {
        return result, errors.New("lockgate: invalid server response")
    }
    return result, nil
}

What the clients do

  1. 1
    Identify the application

    Send POST /api/v1/access with the bearer token and an idempotency key. No path or environment is sent.

  2. 2
    Wait for a decision

    Poll the opaque request ID while the status is waiting_approval.

  3. 3
    Return key/value data

    After approval, return the application’s assigned secret bundle. Values remain in process memory.

  4. 4
    Fail closed

    Denial, timeout, an unreachable server, or an invalid response returns an error.

Where paths and environment belong

The application does not send either value. Its token already identifies the application and environment. Paths remain an admin-side organization and authorization tool.

API responses

StatusMeaningApplication action
waiting_approvalAn administrator has not decided yet.Poll after retry_after seconds.
approvedThe response contains the requested secrets.Configure dependencies and finish startup.
deniedAn administrator denied this request.Fail startup and report a clear error.
revokedThe previous grant is no longer active.Submit a new access request.
401The token is invalid, rotated, or the application is disabled.Stop and fix application credentials.
403A path is outside the application's allowed boundary.Stop; the request will not enter approvals.

Security notes

  • Use HTTPS whenever LockGate is reached across a network.
  • Set a startup timeout. The application must not silently continue when protected secrets are unavailable.
  • Never log application tokens, secret responses, decrypted values, or request bodies containing secrets.
  • Request only the paths the process needs. LockGate rejects paths outside the configured application boundary.
  • Revocation blocks future retrieval. It cannot remove secrets already delivered into an application's memory.
